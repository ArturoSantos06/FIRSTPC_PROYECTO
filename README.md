# FirstPC 🖥️

Plataforma e-commerce para la venta de componentes de hardware y ensamblaje de PC personalizadas.

---

## 📋 Descripción

**FirstPC** es una aplicación web e-commerce diseñada para simplificar la compra de componentes informáticos y asistir a los usuarios en la construcción de su propia PC. Incluye un módulo de ensamblaje interactivo (*PC Builder*) con lógica interna para validar la compatibilidad entre componentes en tiempo real.

---

## 🎯 Objetivo

Proveer a los entusiastas de la tecnología y usuarios generales una plataforma intuitiva que garantice que los componentes de hardware seleccionados para ensamblar una computadora sean 100% compatibles, agilizando el proceso de compra mediante un sistema de e-commerce integral y seguro.

---

## ✨ Características Principales

* **Catálogo de Componentes:** Exploración y filtrado por categorías (procesadores, tarjetas gráficas, memorias RAM, almacenamiento, etc.).
* **PC Builder Interactivo:** Herramienta paso a paso para seleccionar piezas con verificación automática de compatibilidad.
* **Gestión de Estado Global:** Manejo dinámico del carrito de compras y de las configuraciones de PC armadas.
* **Interfaz Moderna y Responsive:** Diseño fluido adaptado para escritorio y dispositivos móviles.
* **Arquitectura Serverless:** Autenticación y persistencia de datos en tiempo real.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React, Tailwind CSS
* **Gestión de Estado:** React Context API & Custom Hooks
* **Backend y Base de Datos:** Firebase Firestore (SDK Modular v9/v10), Firebase Authentication
* **Infraestructura:** Google Cloud Platform / Firebase Serverless (Blaze Plan)

---

## ⚙️ Requisitos

* **Node.js** (v18.0.0 o superior)
* **npm** o **yarn**
* Una cuenta de **Firebase** con un proyecto configurado.

---

## 🚀 Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/ArturoSantos06/FIRSTPC_PROYECTO.git](https://github.com/ArturoSantos06/FIRSTPC_PROYECTO.git)
   cd FIRSTPC_PROYECTO
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

---

## 🔧 Configuración

Crea un archivo `.env` en la raíz del proyecto y agrega tus credenciales de configuración de Firebase:

```env
VITE_FIREBASE_API_KEY=tu_api_key
VITE_FIREBASE_AUTH_DOMAIN=tu_auth_domain
VITE_FIREBASE_PROJECT_ID=tu_project_id
VITE_FIREBASE_STORAGE_BUCKET=tu_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=tu_messaging_sender_id
VITE_FIREBASE_APP_ID=tu_app_id
```

---

## ▶️ Ejecución

Para iniciar el servidor de desarrollo, ejecuta el siguiente comando:
```bash
npm run dev
```
